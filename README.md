A Pharmacy Management System developed using SQL and DBMS to manage medicines, customers, suppliers, employees, purchases, sales, and billing. This project demonstrates database creation, table relationships, primary keys, foreign keys, SQL queries, joins, aggregate functions, and data manipulation operations.
